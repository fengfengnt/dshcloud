用户旅程

两类人，两条路 —— 装机人从一行 curl 到平台可用，普通用户从邀请链接到删除工作空间。

A · 装机人的旅程（宿主上 · 一次性）

A1

跑一行安装

宿主机上 · root · 一行也不问

装机人的操作

把 README 里那行 curl … install.sh | bash 贴进终端

实际发生的事情

四件事，顺序不能换：预检（环境 / 端口 / 存储能力，含 firewalld 冲突探查）→ 宿主上预置存储池 → 取部署资产渲染配置 → 起 Postgres、迁移、起控制面。安装这一步一个问题都不问：账号和域名都不归它管
A2

拿到一行地址

终端打印 · 唯一要复制的东西

装机人的操作

复制终端最后打印的那条 http://<机器地址>:<端口>/setup?token=…，用浏览器打开

实际发生的事情

那一刻平台上还没有账号也没有域名，这页是唯一入口，token 是它唯一的凭证 —— 引导态下整站只开着这一条写口。重跑安装不会换掉它：刻意保留，换了就等于把刚打印给你的链接作废
A3

引导页里建管理员、填域名

浏览器 · 一页填完

装机人的操作

填管理员邮箱、密码、父域；顺手把 *.<域名> 的泛解析指过来

实际发生的事情

页面边填边真探 DNS：解析没就绪会直接给出要加的两条记录。提交后 立刻关掉这个入口并重启 —— 明文的引导口不会留在 80 上；控制台从此落在 console.<域名>。ACME 正在签证书，头一分钟报证书错是正常的
A4

补上实例镜像

管理台 · 最后一块拼图

装机人的操作

登录管理台，进「镜像管理」，把实例镜像设为默认

实际发生的事情

没有默认实例镜像时平台建不了工作空间 —— 装机到此才真正可用。之后日常只剩一条命令：install.sh 重跑即升级（幂等，除非 FORCE_SECRETS=1，绝不重生成 secret —— 换了它，所有实例的门 token 全废）

B · 普通用户的旅程（从邀请到删除）

①

受邀进来

装机人在管理台发出邀请 · 没有公开注册

用户的操作

点开邮箱里的邀请链接，设置密码

实际发生的事情

邀请码核销、账号落库。并发点开同一链接时，真正的闸门是邮箱唯一约束；随后发会话 cookie（Lax、覆盖父域 —— 以后在实例子域上认人要靠它）
②

建工作空间

控制台 · CreateWorkspacePage

用户的操作

填名字、内存、核数、磁盘、镜像版本，点「创建」

实际发生的事情

先有数据，再有实例，五步有先后，任何一步失败实例标 error：
  1. 建数据目录 + XFS 配额（字节与 inode 双限）
  2. 真探宿主端口空闲，分配回环端口
  3. 建独立网络 dsh-net-<slug>
  4. 建容器并启动（入口脚本起 dsh + Caddy 桥）
  5. 落路由：slug.域名 → 127.0.0.1:<port>
③

打开工作空间

浏览器 · slug.域名

用户的操作

点「打开工作空间」，新标签页进入自己的子域

实际发生的事情

Traefik 把每个请求先送控制面认人（forward-auth），是主人才注入按 slug 派生的门 token 转发；容器里 Caddy 验这道 token，再由 dsh 把入口 token 换成 cookie —— 此后地址栏一直是裸域名
未登录302 → 登录页带上 next，登录完跳回来
不是本人403知道这个子域的人不少，能进门的只有主人
是主人200 + 门 tokentoken 按 slug 派生，每个实例一份
④

日常使用

工作空间内 · 编码 agent

用户的操作

让 agent 装依赖、跑命令、读写文件、开仓库

实际发生的事情

全部发生在一个容器 + 绑定存储里。装包、出网、写文件是本职功能 —— 隔离的目标不是拦它们，而是把影响范围限在单个实例内：邻居够不着（独立网络）、磁盘有硬限（XFS 配额）、CPU / 内存 / 进程数由 cgroup 限着
⑤

升级镜像

管理台 · 按实例灰度，不是全站一刀切

用户的操作

在管理台给这个实例选一个新镜像版本

实际发生的事情

停容器 → 先给 /data 打快照 → 落库 → 按新镜像重建。新镜像起不来时自动回滚：数据回快照、镜像回旧版，然后才报错说明原因
⑥

删除

确认之后不可恢复

用户的操作

点删除、确认

实际发生的事情

先优雅停机（让 dsh 把未落盘的会话写完），然后数据真删：容器、数据目录、升级快照、配额账一起清掉；记录留成「退役主机名」，路由条目跟着消失

补③ 那一步里的三道门

三个「门」不是重复设防 —— 它们挡的是三种不同的来客。判断一道门算不算边界，看它的配置放在谁手里。

计入边界
门外 · 认人

forward-auth

每个请求先到控制面：这个子域是谁的？未登录跳登录、不是本人 403，是主人才放行。

控制面（容器外）
不算边界
门内 · 验票

Caddy 门①

验 Traefik 注入的门 token。它挡的是宿主上直连回环端口的其他本地进程 —— 端口发布在宿主回环上，任何本地进程都够得着。

容器内（配置主人可改）
不算边界
门内 · 会话

dsh 门②

把入口 token 换成绑 Host 的 cookie，让地址栏保持裸域名 —— URL 里不出现 token。

容器内（产品功能）

规则只有一条：配置住在容器可写空间里的，都不写进安全论证 —— 它是有效障碍，但能关掉它的只有实例主人。

对旅程每一步背后的边界（实测过）

用户在旅程里感知不到这些数字，它们是隔离方案要维护的东西。全部来自两台宿主上可复现的实测。

旅程动作背后的边界与实测数字
② 创建 XFS project quota —— 限 256 MiB 写 400 MiB，停在 256；inode 限 2000，建到第 1998 个被拒；实例内 df 报配额 256M，不报池子的 448M
③ 打开 每实例一个网络 —— 邻居 TIMEOUT、ARP 表只剩网关一条；接默认桥时邻居 :8080 直接可达（反面对照）
③ 打开 桥端口只发布宿主回环 —— 实例够不到宿主回环；够得到非回环（实测宿主 :22 可达），这条由 --harden-host 堵
④ 干活 cgroup —— pids.max / memory.max 与界面设置逐项一致（真机在跑实例：512 / 2 GiB）
④ 干活 遮蔽表 13 条写死 —— 含 /sys/devices/virtual/dmi：宿主是不是虚拟机、什么机型，实例读不到
